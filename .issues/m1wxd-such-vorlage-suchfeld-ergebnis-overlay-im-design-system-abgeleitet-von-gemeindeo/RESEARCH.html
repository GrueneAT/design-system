01Strategy

Read this first — the rest is detail.

Strategy summary

Destill the mature-but-app-entangled Gemeindeordnung search (src/js/search.js, 1198 lines) into a engine-neutral DS template: a .gat-search* CSS family plus a gat-search.js ESM behaviour module shipped from the DS Pages URL — exactly like gat-charts.js.

  • Mostly extraction, not invention.

    The reference mixes generic UI behaviour (overlay, debounce, modal, Ctrl+K, click-outside) with app specifics (Pagefind calls, Bundesland filter, content-type tabs, stemming). The DS keeps the generic half; the adapter + render-hook keep the rest out.

  • CSS is comfortable; behaviour is net-new.

    .gat-input, .gat-modal (native <dialog>), tokens and the toast fixed/z-index/reduced-motion precedent already exist. Only the .gat-search* family + the ESM module are new.

  • The reference has no arrow-key result nav and no ARIA combobox roles today.

    Both are improvements this issue must add — not a straight port. Same for the focus-trap and reduced-motion handling.

03Decisions

Key decisions & options

Native <dialog> vs. custom backdrop for the modal

Open — recommend <dialog>

The DS .gat-modal is built on native <dialog> + showModal() — free focus-trap, ESC, top-layer backdrop. Recommended basis; gat-search.js only adds returnFocus on close.

The Gemeindeordnung reference deliberately avoids <dialog> with a custom .app-search-modal-backdrop because the sticky trigger lost keyboard focus on close — solved better by returnFocus than by dropping the native element.

Engine coupling

Locked (CONTEXT #3)

Core is engine-neutral: consumer passes async (query) => results[] + an item render/slot schema. A documented Pagefind adapter ships as an optional example, not a bundled dependency.

Header search-trigger styling

Discretion

.gat-header__search is used in Gemeindeordnung markup but does NOT exist in DS CSS (app-local). Recommend adding a DS class (.gat-search-trigger) so the modal-trigger optics live in the DS, not re-built per app.

Don't hand-roll

Pitfalls

No double-debouncing (Pagefind + own), escape meta.title against XSS (excerpt is pre-escaped), no top-level DOM access in the module (SSR/Astro safety), and never edit the minified root CSS (CI diff-checks it).
